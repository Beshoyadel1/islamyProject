# Islamy


An Islamic app built with Flutter: full Quran, Hadith collections, prayer times, live Quran radio and a digital sebha (tasbih counter).


## Features


- Quran: read all surahs
- Hadith: browse hadith collections
- Prayer times
- Quran radio stations
- Sebha: digital tasbih counter
